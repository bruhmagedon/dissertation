# 01. Когда выполняется computed

Один исходный сигнал `count` со значением `1` и одно вычисляемое значение `doubled = count × 2`. Внутри вычисляющей функции выводим «Пересчёт».

## Перед запуском

Прочитай `script.js` и предположи, на каких шагах появится «Пересчёт»:

1. Первое чтение `doubled`.
2. Запись в `count` сначала `2`, затем `3`, без чтения между записями.
3. Чтение `doubled` после записей.
4. Повторное чтение без изменений.

## Запуск из корня репозитория

```bash
cd experiments/01-signal-computed
pnpm install --frozen-lockfile
pnpm start
```

Каждый запуск начинает сценарий заново. В этом опыте нет `effect` и постоянных подписчиков; читаем результат только в обозначенных местах. Вывод в консоль нужен для наблюдения, время работы здесь не измеряем.
