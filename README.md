# Диссертация: лаборатория реактивности

Исследуем, как форма графа зависимостей и частота чтения результатов влияют на число пересчётов и время работы реактивных библиотек.

Стенд использует Preact Signals и Reselect. На примере таблицы сотрудников можно проверить результаты прямым расчётом, измерить одиночные проверки равенства и проверить прогноз на отложенной записи. Новизну и переносимость метода предстоит обосновать.

## Организация

- Каждый эксперимент находится в отдельной папке `experiments/` со своим скриптом, зависимостями и инструкцией запуска.
- Для установки зависимостей и запуска скриптов используем pnpm.
- Код простой и прямой, комментарии короткие и по делу. Следуем `boring-engineering`.
- Продвигаемся по этапам без привязки к срокам. Прогресс кратко обновляем здесь, наблюдения записываем рядом с экспериментом.

## Прогресс

- Освежены основы реактивности на примере Vue Proxy.
- Выбрана отправная точка: один `signal` и один `computed` в консоли.
- Подготовлены структура проекта и первый эксперимент.

- Добавлена запись действий сотрудников, диагностика обоих движков и проверка прогноза на отдельной записи. Порядок демонстрации и команды измерений приведены в [README стенда](experiments/02-sales-graph/README.md).
